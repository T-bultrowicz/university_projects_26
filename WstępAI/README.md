# Introduction to AI

Projects showcasing use of classical methods of machine learning. \
Tasks given require knowledge of how data analysis works and how to properly \
check hypothesis.

### Project - cats

Consists of series of tasks documented in jupyter notebook:
    - Data analysis of colours in png photos of cats & flowers.
    - Compression of images using kMeans clustering.
    - Using kNN to classify images as either cat or flower.

### Project - regression ( more advanced )

Project about developing better methods of classification / regression: \
    - How to properly escape curse of big dimensionality (lot of input data).
    - What methods can we use to generalize better (bias variance tradeoff).
    - How to pick best hyperparameter for models and avoid data leakage.
    - Usage of optuna tool.
