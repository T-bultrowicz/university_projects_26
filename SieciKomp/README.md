# Computer Networks

This folder contains two big projects which I've spent the most \
time during this period and I am the most proud of. This projects taught me \
how to write full working client and server in bare C++, using both UDP and TCP. \
Besides that they taught me how to write own more byte-efficient than HTTP protocols \
and how to write save HTTPS connection using openSSL C library.

### Kayles - Server & client for simple logic game of kayles.
UDP connection and custom protocol.
### Sikradio - Client capable of downloading/playing auditions from radio stations.
Can filter metadata from the stream, uses TCP connection encrypted with SSL.
