# Machine Learning

Mainly resumes traditonal machine learning techniques implemented in scikit-learn \
libraries. Besides that we used torch for neural network project.

### Project - clustering

The task involving clustering images of different images of letters, words, \
buzz noise pixel images. I learned model selection techniques and hyperparameter \
selection for this task.

### Project - classification

Classical task for binary classfication for deep neaural networks, based on problems \
from IEEE Big Data Cup 2022 about image encryption safety. \
Used torch library and ResNet18 for this task.
